Paste an image straight in

⌘V a screenshot, or drag one onto the window. It attaches as a thumbnail you can drop again before sending — the transcript format already carries image+text user turns, so nothing has to be invented for this.

Summon

A global hotkey opens it over whatever you were doing. Esc hides but keeps the draft — a half-formed thought is never destroyed.

Modifier chips

One-tap constraints you'd otherwise retype every time. They append to the prompt and persist per session.

Queue vs send

⇧↵ queues instead of sending, for when the target is mid-task. The format already has a queue-operation record.

Answer without leaving

When a session is blocked on a multiple-choice question, the options render as pickable cards right in the transcript. Number keys select, ↵ sends. "Something else" falls back to free text.

Three waiting states, one colour

Answer, Review and plain You all read as green because they all mean the same thing — it wants you. The glyph says which kind, so the palette doesn't inflate.

Pinned float to the top

A pin keeps a session in its own group above everything, regardless of which window it belongs to. Hover any row to pin it.

Unread is per-session

A dot in the project's hue appears when a session writes output you haven't looked at. Reading it clears the dot.

Who said it, twice over

Your turns get a filled clay badge and a tinted panel with a rule down the left. Claude's sit flat on the glass with an outlined badge.

Grounded, not invented

The Claude Code extension contributes acceptProposedDiff and rejectProposedDiff. These buttons call those — Sidecar isn't writing files itself.

One file at a time

Tabs across the top, with a dot for each file still pending. Accept-all exists, but it's a keystroke away rather than the default button.

Reject is never the loud one

Accept is filled green, reject is an outline. Destructive actions shouldn't compete visually with the thing you'll press ninety percent of the time.

Escape hatch

Anything you'd rather see properly opens in Antigravity at that file, one click.

Frame 06 — the colour system

Three systems that must never be confused

Identity hues stay cool

Every project colour comes from the violet–cyan–magenta side. State is warm amber or mint; action is warm clay. A cool hue therefore never reads as "this needs attention".

Identity gets the smallest surfaces

A 3px swatch, the project name, an unread dot, a bar segment. It never fills a button or a pill, because those belong to the other two systems.

Assigned, then remembered

Hues are handed out from the ring in the order projects first appear, then stored — so a project keeps its colour, and you learn it.

Overridable

Right-click a project to set its hue by hand. Colour-based recognition only works if the colour matches whatever's in your head.

Detail — long titles

A title too long to fit loops itself

Hover any row below. At rest it truncates; once hovered or active, the text loops past continuously, with the next pass arriving as the last one leaves.

A row moves as one

The title and its description share a single distance and duration, and each line's gap is padded so both duplicates land on the same beat. They can't drift apart.

Constant speed

Travel distance sets the duration, so a very long title doesn't race past while a slightly-long one crawls. About 38 px per second either way.

Only when it overflows

Measured per row against its real width. A title that fits is left completely alone — no drift, no wobble.

Quiet by default

Only hovered and active rows move, and prefers-reduced-motion turns it all back into an ellipsis.
